# ИИ-ИДУ

Версия 0.5.0: TMON заменяет свободную долю рублей во всех четырёх стратегиях. Закрытые покупки включаются в единый план и после подтверждения автоматически отправляются при открытии торгов с теми же лимитами и количеством.

Сервис для цели, правил портфеля и исполнения согласованных операций. Python-бэкенд, SQLite, HTML/CSS/JavaScript без сборки. Торговля подключена к песочнице Т-Инвестиций. Реальный счёт используется только для просмотра и аналитики.

## Запуск

Нужны Python 3.10+ и браузер. Сторонних библиотек нет.

```sh
python3 mvp/app.py
```

Открыть [сайт](http://127.0.0.1:8765) или [песочницу](http://127.0.0.1:8765/#sandbox). На macOS также работает `mvp/start.command`. Другой порт: `python3 mvp/app.py --port 8766`. Остановка сервера: Ctrl+C. Для отдельной базы: `--database /path/to/app.sqlite3`.

## Основной путь

1. Открыть [песочницу](http://127.0.0.1:8765/#sandbox) и вставить sandbox token в видимое поле.
2. Выбрать один из четырёх уровней: «Осторожный», «Умеренный», «Сбалансированный», «Динамичный». Диаграмма сразу показывает целевые доли.
3. Указать цель, сумму, срок и ежемесячный взнос. Опыт, подушка и долговые вопросы в demo не собираются.
4. Нажать «Показать покупки». Если счёта ещё нет, приложение создаст его и пополнит на 10 млн виртуальных рублей. До покупки видны бумаги, штуки/лоты, лимитные цены, комиссия и бюджет с запасом.
5. Нажать «Купить активы». Worker отправляет только эту подтверждённую серию. Финальный экран появляется после исполнений и точной сверки всех позиций.
6. «Начать заново» создаёт новый чистый счёт с 10 млн ₽. Прежний счёт и история сохраняются. При активном или неизвестном поручении новый старт заблокирован.

Новая demo-конфигурация отделена от полного инвестпрофиля и реального портфеля; несуществующие ответы анкеты не подставляются. Stop/Resume, отдельное применение правил, ручные заявки и технические настройки убраны из demo UI. Внутренние guards и API остановки сохранены. Выбор риска и редактирование цели сами не вызывают покупку.

Регистрация использует почту как логин, без отправки писем и восстановления пароля. Sandbox token выпускается пользователем по [официальной инструкции](https://developer.tbank.ru/invest/intro/intro/token) и вводится в парольное поле интерфейса.

## Архитектура

Приложение построено как модульный монолит: один процесс, разделённые доменные правила, прикладной сервис, учёт и внешние адаптеры. Его можно передать и запустить целиком; части исполнения не находятся в JavaScript.

| Модуль | Ответственность |
|---|---|
| `app.py` | HTTP, аккаунты, маршрутизация, основной портфель |
| `engine.py` | Валидация профиля/CSV, аналитические формулы |
| `portfolio_policy.py` | Стратегии, допустимость по профилю, версии правил, расчёт целых лотов и объяснения |
| `broker_gateway.py` | Контракт брокерского адаптера для прикладного сервиса |
| `sandbox_service.py` | Подготовка и подтверждение, проверки перед отправкой, worker, остановка, сверка |
| `sandbox_store.py` | Транзакции, предложения, стабильные UUID поручений, статусы и аудит |
| `sandbox.py` | Только sandbox endpoint, рыночные данные и заявки песочницы |
| `tinvest.py` | Только чтение реального счёта |
| `broker_sessions.py` | Раздельные временные подключения в памяти |
| `static/` | Экраны, формы, просмотр статусов; без полномочий обходить проверки |

Детальная [целевая архитектура](docs/ARCHITECTURE.md), [соответствие PRD/SRS/RTM](docs/REQUIREMENTS.md), [путь пользователя](docs/CJM.md), [проверки](docs/VERIFICATION.md).

[Расчётный пример](docs/SANDBOX_SESSION.md): целевые доли и разрыв до цели на условных числах.

Конфигурация цели, правила, исходный снимок, расчёт расходов и согласие связываются с конкретной серией и счётом. Содержимое предложения защищено SHA-256 fingerprint. UUID каждой операции записывается до сетевой отправки; потеря ответа не создаёт повторного POST. Результат ищется по исходному Request UUID. Принятая заявка не считается исполненной, частичное исполнение учитывается по количеству лотов. Данные брокера сверяются с количеством уже подтверждённых исполнений; расхождение блокирует новые поручения. Worker продолжает только подтверждённую серию и проверяет разрешение перед каждым POST.

Worker проверяет статусы и обновляет портфель. В demo завершённая серия сохраняется; новые предложения автоматически не создаются. Legacy API полного профиля может готовить предложения ребалансировки без подтверждения. Background-запросы не продлевают пользовательский idle TTL. После перезапуска нужен токен; учёт, версии, согласия и stop-состояние сохраняются. Перед продолжением выполняется сверка.

## Два контура

Реальный портфель: Read-only token → один счёт → снимок и аналитика. Поддержаны RUB, длинные акции, облигации, фонды и рублёвый остаток. НКД включается в стоимость облигаций, но исключается из изменения чистой цены. Подробности — [T_INVEST.md](docs/T_INVEST.md). CSV и ручной ввод также доступны.

Песочница: отдельный Sandbox token и фиксированный `sandbox-invest-public-api.tbank.ru`. Изменить адрес запросом или переключиться на production нельзя. Рублёвые акции и фонды из разрешённого каталога, лимитные покупки/продажи без плеча. Для фондов сохраняются исходный тикер и площадка; точные пары `TMOS@/SPBRU`, `TGLD@/SPBRU` сопоставляются с инструментами стратегии. Неизвестное совпадение не угадывается.

Четыре стратегии имеют фиксированные версии состава: «Осторожный», «Умеренный», «Сбалансированный», «Динамичный». Уровень риска — условное название сценария, не рассчитанная волатильность. Это настройки sandbox-сценария; их инвестиционная пригодность и universe для реальных денег требуют утверждения. Фонды не раскрываются по составу. Требуемая доходность и прогноз результата не подставляются.

В режиме свежей цены допустим возраст котировки до 30 секунд. Отдельный режим «Последняя сессия» существует только для песочницы и сохраняется в правилах и согласии. Он не выполняет production NFR-2. Время получения денег/позиций у API также не доказывает время актуальности у источника — это открытая часть интеграционного контракта.

## Данные и эксплуатация

Сервер по умолчанию слушает `127.0.0.1`; этот HTTP transport не предназначен для публичного интернета. Целевой public transport, HTTPS, T-ID/delegated consent, права сотрудников, резервирование и эксплуатационные SLO выделены в архитектуре и матрице готовности. Реальные торговые полномочия в этот адаптер не добавляются.

`data/app.sqlite3` создаётся при первом запуске и содержит снимки/учёт. Пароли хешируются PBKDF2 с солью, cookie HttpOnly/SameSite=Strict, изменяющие запросы проверяют Origin/Host. База ограничена правами ОС, но не зашифрована. JSON отчёта не включает token или session key. Токены только в RAM: 30 минут без пользовательского действия, максимум 8 часов. Logout/disconnect/restart очищают временный доступ; отзыв у брокера выполняется отдельно. Уже отправленная операция остаётся в учёте после отключения.

Диагностика доступна в `GET /api/health`, свой полный аудит — в `GET /api/sandbox/report`. Аудит не редактируется через API; production retention, DPO/Legal и политика удаления требуют отдельного решения. Языковая модель пока не подключена: объяснения строятся из сохранённых чисел, передавать модели токены или разрешение отправки архитектура не предусматривает.

## Проверки и передача

Из корня проекта:

```sh
python3 -m unittest discover -s mvp -v
node --check mvp/static/app.js
node --check mvp/static/broker.js
node --check mvp/static/sandbox.js
python3 mvp/scripts/package.py
```

Автотесты используют отдельные SQLite-базы и ответы FakeBroker/FakeSandbox, без пользовательского токена. Часть тестов поднимает loopback-сервер. Node нужен только для проверки синтаксиса. Скрипт упаковки включает код, инструкции, тесты, ресурсы, четыре актуальных документа требований и новый экран sandbox demo. Базы, токены, кэши и снимки реального портфеля не входят в архив.

Старая синтетическая практика оставлена в API ради совместимости данных, но не входит в основной путь песочницы и не учитывается как исполнение брокером. Полный статус 13 FR и 8 NFR указан в матрице: нагрузки, 30-дневного наблюдения, полного восстановления, production-допуска и пилотных KPI этот запуск не доказывает. Демонстрационные 10 млн ₽ не меняют цель пилота 2 млн ₽.
