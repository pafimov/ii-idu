# Т-Инвестиции: личный доступ к аналитике

Адаптер реального счёта работает только для чтения. Для торговли предусмотрен отдельный sandbox-контур со своей конфигурацией и временным подключением. [Текущий путь](CJM.md), [проверки](VERIFICATION.md). Ниже описаны границы read-only адаптера.

Дата проверки: 15.10.2026. Пользователь выбрал реальный портфель только для просмотра и аналитики. Это личный локальный сценарий, не согласованный способ подключения клиентов массового продукта.

## Путь пользователя

Локальный аккаунт → «Брокер» → Read-only токен → согласие получить доступные счета → выбор одного счёта → согласие заменить снимок → аналитика. Анкета не обязательна для просмотра структуры. Для тренировочной торговли профиль и отдельное согласие нужны по-прежнему; реальные позиции не переходят в тренажёр.

Создание и отзыв токена выполняются пользователем в Т-Инвестициях: [официальная инструкция](https://developer.tbank.ru/invest/intro/intro/token). Приложение не изображает вход по T-ID и не запрашивает полный доступ. Токен вводится только в приложении, не в чат. Поле очищается при отправке; token не попадает в состояние интерфейса, выгрузки и события.

## Данные и ограничения

Поддерживаются открытый брокерский счёт и ИИС, положительные количества рублёвых акций, облигаций, ETF/фондов и RUB. Количество трактуется в штуках, а не лотах. Максимум 60 бумаг на брокерский снимок. Фонды не раскрываются по составу. Неизвестный сектор остаётся неизвестным.

Валютные позиции, короткие позиции, производные инструменты, неизвестный вид актива и ненулевой заблокированный денежный остаток отклоняются целиком. Документация не даёт достаточно однозначного основания прибавлять заблокированные деньги к `money`, поэтому приложение не угадывает эту сумму. Заблокированные бумаги учитываются в стоимости с предупреждением; возможность их продажи не утверждается. Несогласованность количеств или сумм между ответами API также отклоняет обновление. Последний успешный снимок сохраняется.

Количество сверяется между GetPortfolio и GetPositions (`balance + blocked`). Итоги классов и всего портфеля, если они присутствуют в ответе, сравниваются с рассчитанными суммами с допуском 1 ₽. Остаток денег берётся из GetPositions, а не восстанавливается разницей итога и бумаг. Скрытой корректирующей позиции нет.

Для облигации: стоимость = количество × (currentPrice + currentNkd). Изменение цены = количество × (currentPrice − averagePositionPrice). В знаменателе процента используется средняя цена без текущего НКД. Это изменение открытых позиций относительно средней цены, не полная доходность: купоны, дивиденды, комиссии, налоги и закрытые сделки не включены. При нулевой базе процент отсутствует. Поля чистых цен, НКД и блокировок доступны в JSON и расширенном CSV. Этот CSV не является входным восьмиколоночным форматом ручного импорта.

Набор ответов не является атомарным биржевым снимком: если во время загрузки счёт изменился, проверка может попросить повторить обновление. Время получения показано отдельно, время котировки API здесь не подтверждает. После закрытия рынка оценка может опираться на последние цены закрытия. Автоматического обновления и потока котировок нет.

## Доступ

Python использует только семь разрешённых методов: GetAccounts, GetPortfolio, GetPositions, GetInstrumentBy, ShareBy, BondBy, EtfBy. Адрес API фиксирован, TLS проверяется; перенаправления и системные proxy отключены. Ответ ограничен 2 МБ, один запрос — 10 секундами, общий бюджет загрузки — 45 секундами с проверкой между запросами. Метод отправки заявки отсутствует.

GetAccounts проверяет права всех возвращённых счетов: FULL и неизвестные права отклоняются, NO_ACCESS пропускается. Это проверка доступной области токена, не доказательство прав на не возвращённые API счета. Поэтому пользователь должен выпустить именно Read-only токен. Перед обновлением права проверяются заново.

Токен хранится в памяти процесса, привязан к владельцу и текущей сессии: 30 минут без операций с брокером, максимум 8 часов. Фоновая очистка работает каждые 30 секунд; при обращении срок проверяется сразу. Другой аккаунт или сессия не получает токен. Выход и отключение очищают текущую сессию, удаление аккаунта — все его подключения, перезапуск — все подключения процесса. Отзыв у брокера выполняется отдельно. При ошибке авторизации временный доступ удаляется.

Сеть не вызывается при обычном просмотре кабинета или выгрузке отчёта. Сеть работает вне транзакции записи SQLite. После ответа повторно проверяются сессия, версия портфеля и актуальность подключения. Отключение или ручная замена во время запроса не позволяет позднему ответу перезаписать данные. Одновременное обновление одного подключения блокируется.

SQLite хранит снимок и метаданные счёта, но не токен. База не зашифрована. Доступ разрешён только с компьютера пользователя; перенос этого HTTP-сервера в публичный интернет не является предусмотренным режимом.

## Проверки и неизвестное

54 автоматических теста прошли; в браузере пройден путь на отдельном сервере с подменёнными ответами: подключение → выбор → сумма 2 510 ₽ → обновление → отключение с сохранением снимка. Мобильная форма проверена при ширине 360 px. Независимые Security/SRE и quant/UX reviews завершены после исправлений. Это не пентест. Запрос к официальному API без авторизации вернул 401 при включённой проверке TLS; это подтверждает доступность адреса, но не работу с реальным пользовательским счётом. Такая проверка ожидает самостоятельного ввода токена пользователем.

Сильнейший контраргумент к этому пути: ручной выпуск токена и ограниченное покрытие активов создают трение и могут не подойти реальному составу счёта. Уверенность высокая в проверенных локальных свойствах, неизвестная в реальных ответах конкретного счёта и конверсии. Изменить границы помогут обезличенные реальные примеры неподдержанных ответов и согласованный интеграционный контракт. Правила внешнего продукта, права на данные, delegated consent и эксплуатация остаются отдельной задачей владельцев платформы, Legal, Compliance и Security; D-005/D-006 не отменены.

## Первичные источники

Издатель всех источников — Т-Банк / T-Invest API. Дата публикации страниц не указана; доступ и повторная проверка 15.10.2026.

- [Токены](https://developer.tbank.ru/invest/intro/intro/token): Read-only, выпуск и отзыв.
- [UsersService](https://developer.tbank.ru/invest/services/accounts/users): доступные счета и access_level.
- [OperationsService: методы](https://developer.tbank.ru/invest/services/operations/methods): поля позиций, количества, цены и НКД.
- [GetPortfolio REST](https://developer.tbank.ru/invest/api/operations-service-get-portfolio): адрес и параметры.
- [Операции и портфель](https://developer.tbank.ru/invest/services/operations/head-operations): оценки при закрытом рынке, ограничения сервиса.
- [InstrumentsService](https://developer.tbank.ru/invest/services/instruments/methods): идентификаторы и типизированные данные инструментов.
- [FAQ](https://developer.tbank.ru/invest/intro/faq): область стандартного личного API и ограничение публичного сервиса. Специальный контур проекта не считается предоставленным этим FAQ.
