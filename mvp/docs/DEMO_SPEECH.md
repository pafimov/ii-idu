# Рассказ на две минуты

Около двух минут при темпе 130–140 слов в минуту. Текст от лица команды.

Мы сделали рабочий MVP сервиса, который помогает человеку понять свой портфель и пройти путь от финансовой цели до покупки активов. Сегодня покажем его в песочнице Т-Инвестиций.

Пользователь подключает токен, а при первом расчёте приложение создаёт виртуальный счёт с десятью миллионами рублей. Дальше пользователь задаёт цель, срок, ежемесячный взнос и выбирает одну из четырёх готовых стратегий по риску. Состав виден сразу: фонд денежного рынка TMON, золото, российские акции. Достижение цели считаем отдельно, по текущему капиталу и взносам, без предположения о доходности.

«Показать покупки» переводит доли в конкретные бумаги и целые лоты. Приложение проверяет доступность торгов, лимитные цены, комиссии и достаточность денег. Пользователь видит весь план и подтверждает одной кнопкой.

Мы учли закрытые инструменты. Доступные заявки отправляются сейчас, остальные ждут открытия и отправляются автоматически с подтверждёнными количеством и лимитом. Статусы видны отдельно; деньги под ожидание учитываются в расчёте приложения, но не блокируются у брокера. Оставшиеся покупки можно отменить.

Технически это модульное приложение на Python с базой SQLite и веб-интерфейсом. Расчёт стратегии, работа с брокером и учёт заявок разделены. Каждая операция получает уникальный идентификатор. При потере ответа система сначала выясняет результат, чтобы не повторять заявку вслепую. Реальный портфель подключается отдельно, только для просмотра и аналитики.

Сейчас работают прозрачные правила; языковую модель ещё не подключали. Она сможет помогать с диалогом и объяснениями, а разрешение на сделки останется в контролируемой логике.

Прошли 154 автоматических теста и фактические виртуальные покупки через API брокера. Отправку после открытия проверили моделируемым тестом. Есть работающий сценарий, подтверждённые позиции, аналитика цели и история операций. Код опубликован на GitHub; следующий этап — целевая авторизация и исполнение для реального продукта.
